AutoDelphiRF

AutoDelphiRF automates revision nowcasting from a raw surveillance archive: it diagnoses the reporting pattern, configures the forecast, and evaluates performance without preliminary data exploration. It forecasts one indicator from its own revision history so the adjustment remains independent for downstream use. This development interface supports a one-time retrospective analysis that mimics real-time forecasting with rolling training and evaluation windows.

This web interface is in development. Feedback on the workflow, explanations, and results is welcome.

How long until reported values are sufficiently stable?

Recreate historical real-time forecasts

At each report-date origin, the model trains only on reports available at that time and is evaluated on later data. This prevents future-information leakage and recreates real-time revision forecasting.

Revision patterns usually do not change every day, so the model can be retrained less often than new reports arrive. Choosing the retraining interval balances faster adaptation against computational cost.

Which methods should run?

The defaults are the smallest run that answers “is routing worth anything on my data”. The rest fit forests and take substantially longer.
